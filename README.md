# Portafolio · Stiven

Landing de presentación con cinco proyectos reales en producción: sitios
institucionales, portales educativos con panel y landings de negocio.

**Demo:** https://stiven211.github.io/portafolio/

## Proyectos

- IEJCM · Colegio José Celestino Mutis
- Ciencias y Tecnología
- EcoProgramadores STEAM
- Expoguaviare · SENA
- Taxi VIP · San José del Guaviare

## Stack

HTML, CSS y JavaScript sin dependencias ni build. Tipografías Sora e Inter.
Desplegado con GitHub Pages.

## Local

Abre `index.html` en el navegador o sirve la carpeta:

```powershell
python -m http.server 8080
```
