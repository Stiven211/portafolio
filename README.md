# Portafolio · Stiven

Landing de presentación con cinco proyectos reales en producción y seis micro
demos de sistemas: sitios institucionales, portales educativos con panel,
landings de negocio y productos funcionales en miniatura.

**Demo:** https://stiven211.github.io/portafolio/

## Contacto

El formulario usa FormSubmit para enviar a `kurregorojas@gmail.com` sin backend.
La primera vez hay que confirmar el correo de activación que llega a esa bandeja.
Incluye captcha, campo honeypot y validación en el navegador.

La API key de Resend no se incluye en el frontend. Para usarla hay que crear una
función serverless y guardarla como variable de entorno.

## Stack

HTML, CSS y JavaScript sin dependencias ni build. Tipografías Sora e Inter.
Desplegado con GitHub Pages.

## Local

Abre `index.html` en el navegador o sirve la carpeta:

```powershell
python -m http.server 8080
```
